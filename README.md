# МедиаКоми 🏡

Мини-игра по данным объявлений Avito о квартирах в Республике Коми: игрок видит фотографии и описание квартиры, двигает бегунок и угадывает цену. После каждого раунда — реальная цена, разница и очки. После 10 раундов — ценовой портрет: **Жадный студент**, **Адекватный квартирант** или **Транжира**.

## Запуск локально

Достаточно любого статического сервера:

```bash
cd mediakomi
python3 -m http.server 8080
# открыть http://localhost:8080
```

(Можно просто открыть `index.html` двойным кликом — сборка не требуется.)

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `mediakomi`).
2. Загрузите файлы `index.html`, `style.css`, `app.js`, `data.js`:

   ```bash
   git init
   git add .
   git commit -m "МедиаКоми: игра «Угадай цену квартиры»"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/mediakomi.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Через минуту игра будет доступна по адресу `https://<ваш-логин>.github.io/mediakomi/`.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Разметка трёх экранов: старт, раунд, итоги |
| `style.css` | Стили в фирменном цвете HSE `#012D6E`, mobile-first |
| `app.js` | Игровая логика, балльная система, архетипы |
| `data.js` | 36 активных объявлений (фото, цена, ссылка) — сгенерирован из CSV |

## Балльная система

Очки за квартиру зависят от относительной ошибки оценки `|ваша цена − реальная| / реальная`:

| Ошибка | Очки |
|---|---|
| ≤ 5% | 100 |
| ≤ 10% | 80 |
| ≤ 20% | 60 |
| ≤ 35% | 30 |
| ≤ 60% | 10 |
| > 60% | 0 |

Максимум за игру — **1000 очков**. Ценовой портрет определяется по среднему смещению: систематически ниже реальных цен → «Жадный студент», выше → «Транжира», в пределах ±7% → «Адекватный квартирант».

## Обновление данных

Файл `data.js` генерируется из CSV с объявлениями (скрипт парсинга сохраняет колонки: ссылка, фото, цена, описание, улица; объявления без фото отбрасываются).
